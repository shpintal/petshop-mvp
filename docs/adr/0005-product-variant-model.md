# ADR-0005: Модель Product → Variant

Статус: Прийнято (2026-10-28)

## Контекст
У as-is кожна вага — окремий товар з окремим URL; відгуки розпорошені, дубль-контент.

## Рішення
Product (опис, бренд, атрибути, відгуки) → Variant (SKU, вага/обсяг, EAN, ціна, залишки). Один URL на Product, вибір варіанта — параметр `?v=`. Ціна за одиницю обчислюється.

## Наслідки
Агреговані відгуки та рейтинг, чистий SEO. Потрібна міграція «склеювання» товарів у разі імпорту з as-is.
