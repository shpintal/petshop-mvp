# ADR-0002: Модульний моноліт на NestJS + Fastify

Статус: Прийнято (2026-10-28)

## Контекст
Команда до ~10 осіб; мікросервіси на старті додають операційної складності без вигоди.

## Рішення
Один деплойний артефакт, модулі = bounded contexts, взаємодія через сервіси й доменні події, outbox для зовнішніх ефектів. Fastify замість Express — продуктивність, вбудована схема-валідація, `inject()` для тестів без мережі.

## Наслідки
Простий деплой і транзакції; можливість винести модуль (search, integrations) у сервіс. Ризик — «розмивання» меж; контролюється лінтером залежностей.
