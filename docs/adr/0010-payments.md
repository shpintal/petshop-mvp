# ADR-0010: Платежі: адаптери провайдерів, відкладена оплата, ідемпотентність

Статус: Прийнято (2026-10-28)

## Контекст
Потрібні LiqPay, Monobank, Apple/Google Pay, оплата пізніше з кабінету, накладений платіж.

## Рішення
`PaymentProvider { createPayment, verifyWebhook, refund }`; ключ ідемпотентності на замовлення; перевірка підпису вебхука; стан-машина платежу.

## Наслідки
Відсутність подвійних списань, легке додавання провайдера.
