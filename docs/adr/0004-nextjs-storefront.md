# ADR-0004: Вітрина на Next.js App Router (RSC, SSR/ISR)

Статус: Прийнято (2026-10-28)

## Контекст
SEO — ключовий канал залучення; потрібні швидкий перший рендер і динамічні дані (ціни, наявність).

## Рішення
Next.js 16 App Router: RSC для каталогу й PDP (ISR з ревалідацією за подією зміни ціни/залишку), клієнтські компоненти лише для кошика й інтерактиву. Metadata API для canonical/hreflang, JSON-LD, sitemap.ts.

## Наслідки
Високі Core Web Vitals, повний контроль SEO. Потрібна дисципліна кешування та інвалідації.
