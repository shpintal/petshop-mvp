# ADR-0013: Спостережуваність і розгортання

Статус: Прийнято (2026-10-28)

## Контекст
Потрібні швидкі релізи й діагностика інцидентів.

## Рішення
OpenTelemetry (трасування, метрики, логи), контейнери, CI/CD з canary, Cloudflare перед web/api, IaC (Terraform).

## Наслідки
Передбачувані релізи, MTTR у хвилинах.
