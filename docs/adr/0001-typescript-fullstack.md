# ADR-0001: TypeScript full-stack монорепозиторій

Статус: Прийнято (2026-10-28)

## Контекст
Потрібна одна мова для вебу, API та мобільного застосунку; великий ринок розробників; спільні типи.

## Рішення
Next.js (вітрина, back-office), NestJS (API), Expo (мобільний). Спільні контракти — OpenAPI → згенерований TS-клієнт.

## Наслідки
Однорідний стек і повторне використання коду. Мінус: вся e-commerce логіка пишеться самостійно (на відміну від готових платформ).
