# ADR-0012: AI-консультант через RAG з guardrails

Статус: Прийнято (2026-10-28)

## Контекст
Консультації — ключова цінність офлайн-мережі; потрібно перенести її онлайн.

## Рішення
LLM + retrieval по каталогу, атрибутах складу і довідці про породи; відповіді містять лише товари з каталогу; заборона медичних діагнозів; логування та оцінка якості.

## Наслідки
Масштабована консультація 24/7. Ризики: галюцинації (пом'якшуються RAG і валідацією SKU), вартість токенів.
