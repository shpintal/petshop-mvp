# ADR-0011: Вхід за OTP по телефону, картка лояльності прив'язана до телефону

Статус: Прийнято (2026-10-28)

## Контекст
Офлайн-клієнти ідентифікуються за телефоном; паролі — бар'єр.

## Рішення
Passwordless OTP (SMS/Viber), короткі access-токени + refresh у httpOnly cookie; адміністративний доступ — SSO + MFA.

## Наслідки
Менше тертя при вході та єдина ідентичність онлайн/офлайн. Залежність від SMS-провайдера, захист від SMS-pumping (rate-limit, CAPTCHA).
